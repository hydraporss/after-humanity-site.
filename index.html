Opens the files you already have

Choose Open data and pick a file, or drop it into the window. The app works out what it is from the file extension.

.csv.tsv.xlsx.xls.ods.json.parquet.html.xml.txt.log.md.pdf.docx.zip

Legacy .xls, .ods and Parquet need small optional add-ons. CSV and TSV files are read with automatic detection of Windows-1252 encoding and ; or | delimiters. Files inside a ZIP are opened directly, without being unpacked to disk.

Two workspaces, one window

A dark navy interface with a ribbon toolbar, left navigation, global search and a right-hand Intelligence Hub.

Tables and datasets

Understand a file before you trust it.

  • Profiling. Row and column counts, data types, missing values (count and percentage), distinct values, duplicate rows, numeric range, mean, median, IQR outliers and memory use.
  • Statistics and correlation. Descriptive statistics for every column, plus a Pearson correlation matrix for numeric ones.
  • Chart builder. Histogram, scatter, line, bar, box and correlation heatmap. Pick X and Y, group by colour, choose an aggregation. Charts render offline with Plotly.
  • Cleaning and export. Remove exact duplicate rows, then export to CSV, Excel, JSON or Parquet. Your original file is never overwritten.

PDF Intelligence

Get evidence out of a PDF, with the page it came from.

  • Text by page. Extracted page by page, with a SHA-256 fingerprint of the source file and page coverage so you can see which pages had little or no selectable text.
  • Candidate tables. Tables found by pdfplumber are listed with their cells and source page.
  • Structure and references. Heading candidates, plus DOI, URL and email candidates, with a rough document classification.
  • JSON report. Save the full report, including page text, table cells, metadata and evidence identifiers, for use in other tools.

Reports you can hand over

One click from dataset to document.

  • PDF or Word. Generated dataset reports include an overview, column profiles, a missing-data summary, the strongest numeric correlations, distribution charts and a timestamp.
  • Large data stays usable. Charts draw from a fixed sample of up to 200,000 rows, and report charts from up to 100,000. Your data itself is never reduced.
  • Fails softly. Errors are written to a log at %LOCALAPPDATA%\PyDataStudio\logs\application.log instead of taking the app down.

Plain about what it does and doesn’t do

The app labels unavailable features rather than faking output, and this page does the same.

Works today

  • Table work: import, preview (first 1,000 rows), profiling, statistics, correlation, charts, duplicate removal, export.
  • PDF work: text extraction, candidate tables, headings, DOI, URL and email candidates, JSON report.
  • Reports: dataset reports as PDF and DOCX.
  • Privacy: files are processed locally and nothing is uploaded.

Not included yet

  • OCR: scanned, image-only PDFs aren’t read. An optional add-on needs Tesseract installed separately.
  • Entity extraction and knowledge graph: the tabs exist but aren’t implemented.
  • AI answers and insights: they need a provider you configure. None is connected by default.
  • Undo/redo, database connections and multi-file joins.
  • Session recovery: loaded data lives in memory until you close the app.

Table and PDF detection is best effort. Check extracted tables and references against the original document before relying on them.

Get started

This release ships as source. Build the Windows app yourself, or run it directly with Python.

  1. Install Python

    Python 3.12 is recommended; 3.10 to 3.13 work. Use a Windows 10 or 11 (64-bit) PC with internet access for the first build.

  2. Unzip the source somewhere with a short path

    For example C:\PyDataStudio.

  3. Double-click Build-EXE.bat

    It creates a build environment, installs dependencies, runs the tests and produces dist\PyDataStudio\PyDataStudio.exe. Zip and share the whole PyDataStudio folder.

Prefer a single file?

Run the build with the one-file option. It’s larger and starts more slowly, because it unpacks to a temporary folder on each launch.

Build-EXE.bat -OneFile

Run from source instead

Install the requirements and the desktop extras, then launch the app.

pip install -r requirements.txt
pip install ".[desktop]"
python app.py

Expect a 400 to 700 MB build because Qt WebEngine and Plotly are large. The EXE is unsigned, so Windows may show “Windows protected your PC”. Choose More info, then Run anyway, or sign it with your own certificate. The build was prepared on Linux, so run a smoke test on Windows before sharing it widely.

Where it’s heading

Ideas from the project roadmap. None of these are in v0.7.1.

  • OCR adapter with language selection and per-page fallback for scanned PDFs.
  • Layout and reading order reconstruction with source coordinates.
  • Table validation across pages, with export to CSV and XLSX.
  • Interactive data preparation such as filtering, group-by, joins and undo/redo.
  • Large-file handling and a signed Windows executable.
